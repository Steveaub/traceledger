# TraceLedger

Source-grounded project intelligence. This public evidence-only demo uses fictional project records and conversations plus public DOE references. Live email, Slack and Teams accounts are not connected. The investigation controller is deterministic, not an LLM planner. Evaluation metrics and limitations are visible in the app.
